# Weather Now

A weather app UI built as a [Frontend Mentor](https://www.frontendmentor.io) challenge.

## Live site
https://adrew129.github.io/weather-now129/

## Built with
- HTML
- CSS (Flexbox and Grid)

## What I learned
- Planning a dashboard layout with Flexbox and Grid
- Using `gap` instead of many margins to control spacing
- Styling a custom scrollbar for a dark theme

## Challenges
Spacing between sections and the daily forecast cards were the hardest parts. I'm still improving them.

## Next steps
- Make the layout fully responsive
- Add JavaScript and connect the Open-Meteo API (search, unit conversion, real forecasts)
